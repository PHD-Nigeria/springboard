# Springboard Admin & Editorial User Guide

A training guide for PHD Nigeria administrators, editors, and editorial
staff using the Springboard Admin — written for first-time, non-technical
users. Every chapter explains what a feature is and why it exists before
explaining how to use it, and every screenshot is a real capture of the
current Springboard Admin and public site.

**New to Springboard? Start with [Understanding Springboard](01-understanding-springboard.md)**
before jumping to any other chapter — it introduces the ideas (and one
important source of confusion) every later chapter assumes you already
know. From there, work through the chapters in order, or jump straight
to the one covering what you need to do today.

You'll need an existing Springboard Admin account to follow along —
if you don't have one yet, see
[User Management](10-user-management.md#1-what-is-a-user-and-what-is-a-role)
for how accounts are set up.
